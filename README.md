## Why the code you copied usually fails

Three things go wrong, and none of them mean the code was fake.

**One code per order.** Macy's checkout accepts a single promo code. If you try to enter a 25% signup code and a category code, the second one gets rejected rather than stacked. Some offers are structured differently — the app-only "extra $20 off $100+" offers run on their own track and the terms explicitly say they can't be combined with any coupon, extra discount or credit offer except opening a new Macy's account.

**The exclusion list is the real discount limit.** Macy's publishes full exclusions for app-only offers, and they're extensive: furniture, mattresses, gift cards, third-party sellers, athletic shoes, plus a brand list covering Nike, Dyson, Le Creuset, UGG, Coach, The North Face, KitchenAid, Shark, Vitamix, Samsung-adjacent electronics and plenty more. A 30% code sounds broad until you read what's carved out.

**Coupon aggregators are paid per click, not per working code.** An expired code costs the aggregator nothing and costs you a checkout attempt. The reliable codes are the ones Macy's publishes itself, or the ones your cashback platform lists.

One practical consequence: if you're shopping a heavily excluded category — Apple, fine jewelry, cosmetics, mattresses — the discount has to come from somewhere other than a percentage-off code. Macy's clearance, Backstage and the app-only offers are where that usually happens.

ShopBack's own Macy's guidance reads like the list of things people get wrong, so it's worth following literally:

1. **Clear your Macy's cart first.** Existing cart contents can break the tracking for that order.
2. **Close the Macy's app, then open the cashback platform** and click through to Macy's from there.
3. **Do the whole purchase in one go.** Don't switch tabs to read a review, don't click a Google Shopping result, don't open the Macy's app mid-session. Any of those can overwrite the tracking cookie.
4. **Turn off ad blockers and VPNs.** Both interfere with the affiliate redirect that records your order.

6. **If payment fails, restart from the cashback platform.** A retry inside the same broken session usually doesn't track.

The reason for all of this: cashback is recorded through an affiliate redirect, not by reading your bank statement. Break the session and there's nothing to credit. ## Questions people actually ask

**Does Macy's let me stack coupon codes?**
No. One code per order in the standard checkout flow. Cashback and Star Rewards points can stack with a code; two codes can't stack with each other.

**Can I still earn cashback if I use a promo code?**
Only if the code is one ShopBack lists on its Macy's page. Codes from other coupon or cashback sites are explicitly excluded from cashback earning.

**When does Macy's cashback confirm?**
Tracking usually shows within about 2 days, with confirmation around 90 days after purchase, once the return window closes.

**Does a price adjustment cancel my code discount?**
Roughly. Macy's price adjustments generally don't apply if you used a promo code on the original purchase, so you're usually choosing between the code now and a possible adjustment later — not both. The window is around 10 days from the order date.

**Why did my cashback not track?**
The usual causes are an ad blocker, a VPN, clicking through from another site mid-session, buying inside the Macy's app instead of the tracked browser session, or an excluded product in the basket. Missing cashback is worth chasing with your order confirmation, since platforms can investigate a claim — but an order that used an unlisted promo code will typically be declined.

**Is 2% worth the extra step?**
On a $200 order, about $3. On a $40 order, about $0.80. If you're already buying through a coupon code that Macy's itself published and ShopBack lists, the step costs you nothing but a click. If you'd be giving up a 25% signup code to chase it, keep the code.
